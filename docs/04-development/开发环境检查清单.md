## 🔧 常见问题修复

### 问题 1: Node.js 未安装

**症状**: `node --version` 提示命令不存在

**解决方案**:
1. 访问 https://nodejs.org/
2. 下载 LTS 版本（推荐 18.x 或 20.x）
3. 安装后重启命令行
4. 验证: `node --version`

### 问题 2: Python 未安装

**症状**: `python --version` 提示命令不存在

**解决方案**:
1. 访问 https://www.python.org/
2. 下载 Python 3.9+ 版本
3. 安装时勾选 "Add Python to PATH"
4. 安装后重启命令行
5. 验证: `python --version`

### 问题 3: 前端依赖未安装

**症状**: `node_modules` 目录不存在

**解决方案**:
```bash
# 安装依赖
npm install

# 如果失败，清除缓存重试
npm cache clean --force
npm install
```

### 问题 4: 后端依赖未安装

**症状**: `backend\venv` 目录不存在

**解决方案**:
```bash
# 创建虚拟环境
cd backend
python -m venv venv

# 激活虚拟环境
venv\Scripts\activate.bat  # CMD
# 或
.\venv\Scripts\Activate.ps1  # PowerShell

# 安装依赖
pip install -r requirements.txt
```

### 问题 5: .env 文件不存在

**症状**: 启动时提示找不到 .env 文件

**解决方案**:
1. 确保项目根目录有 `.env` 文件
2. 如果没有，创建一个并配置必要的环境变量
3. 参考 `.env.example`（如果有）

### 问题 6: 端口被占用

**症状**: 启动时提示端口 3000 或 8000 已被占用

**解决方案**:
```bash
# 停止现有服务
scripts\stop-dev.bat

# 或手动终止进程
netstat -ano | findstr :3000
taskkill /F /PID <进程ID>
```

### 问题 7: PowerShell 执行策略错误

**症状**: 运行 .ps1 脚本时提示执行策略错误

**解决方案**:
```powershell
# 以管理员身份运行 PowerShell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```
