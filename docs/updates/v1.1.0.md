# 智护银龄 v1.1.0

发布日期：2026-07-14

## 重点更新

- 家属端正式定位为监护协作端：统一选择当前照护长辈，健康、用药与首页看板不再读取家属本人数据。
- 家庭关系改为长辈相对家属的称谓（父亲、母亲、爷爷、奶奶等），并按健康查看、健康代录、用药管理权限分域。
- 家属与长辈都可配置用药计划、提醒与服药确认；应服发生项持久化，历史依从率不会被后续计划修改重写。
- 家属看板新增今日用药、七日依从率、心率趋势与异常统计。
- 语音陪伴固定使用 `mimo-v2.5-pro`：完整健康数值可写入健康记录，日常内容可整理为私密碎碎念。
- 只有长辈明确同意后，碎碎念才会原子同步给全部 active 家属；消息列表和气泡展示“碎碎念”标签。
- 新增 v1.1.0 更新通知页与“关于我们”页，项目归属为华中科技大学基础医学院“慧老智治医心为民”AI智慧医养暑期实践项目。
- 统一 44 / 48 / 52px 按钮、共享开关与卡片视觉；底栏当前项改为图标填色，不再显示局部圆形高亮。

## 性能与稳定性

- 同账号并发 GET 在途合并，请求完成即释放，不缓存陈旧健康数据。
- 联系人最新消息与未读数由一次 Supabase RPC 聚合，打开会话后一次批量标记已读。
- 家属首页继续通过单 RPC 返回最小统计集，避免按卡片数量放大数据库请求。
- 生产构建保持 `.next` 全栈输出；静态 CSS、JavaScript 与 EdgeOne 单文件预算全部通过。
