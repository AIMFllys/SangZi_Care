# 智护银龄 v1.3.0

发布日期：2026-09-09

## 这次更新解决了什么

v1.3.0 补上问卷入口、开屏与登录提示，并重做登录页。网页、`/api/ping` 和 Android 壳的版本信息统一为 1.3.0。

## 主要变化

### 健康早筛问卷

- 题目、选项和权重与 `Elderstech-Questionnaire` 关爱同行问卷保持同步。
- 首页、健康、用药、消息、设置右上角提供问卷入口。
- 按模块分页填写，性别专属模块可跳过；提交后给出 0–10 风险回执。

### 开屏与登录提示

- 浏览器首次进入播放标识与「智护银龄」字标动画。
- Android 壳在 WebView 加载期间展示原生开屏，避免白屏。
- 未登录访问受保护页面时，先弹出说明，确认「去登录」后再进入登录页，不再静默跳转。

### 登录页

- 邮箱、算术确认、验证码拆成三步，始终显示标签，验证码用六格提示。
- 窄屏仍使用紧凑发送文案，登录成功后整页导航以刷新认证上下文。

## 数据库与部署提醒

本版本无新的数据库迁移。Android 是在线 WebView 壳，正式包的 `versionName` 为 `1.3.0`、`versionCode` 为 `4`。网页功能需先部署到 EdgeOne 后，已安装的在线壳打开新网页即可获得；系统设置中的版本号需要重新安装 APK。

## 验证记录

- Vitest、TypeScript、ESLint、Next.js production build 通过。
- 未提交任何 `.env`、密钥或真实用户数据。
