# 智护银龄 v1.2.0

发布日期：2026-08-13

## 这次更新解决了什么

v1.2.0 是一次围绕“消息可靠、AI 反馈清楚、健康记录不丢、紧急求助可追踪”的体验更新。网页、`/api/ping` 和 Android 壳的版本信息统一为 1.2.0。

## 主要变化

### 消息与 AI 语音

- 语音转写结果会自动进入可编辑文字草稿，手动输入内容不会被误覆盖。
- 文字发送和语音发送保持清晰分流，取消、重录、空转写和识别失败不会污染下一轮草稿。
- AI 回复卡支持长文本在卡片内部滚动，底部录音和结束对话控件不会被长回复挤出屏幕。
- AI 工具动作会明确显示成功、提醒或失败，不再把结构化动作对象误当成普通语音文本朗读。
- 消息联系人支持个人备注、置顶、长按操作和稳定排序；备注不会泄露给另一位用户。

### 紧急求助

- 紧急求助使用一次性原子通知流程，避免只写入事件却没有通知消息。
- 快速重复点击不会重复触发同一请求；网络失败可以安全重试，确定性冲突不会形成死循环。
- 没有可通知家属时会明确提示，而不是伪装成“已发送”。
- 定位读取有明确时间上限，无法及时取得定位时仍可提交无定位求助。

### 健康记录

- 不同健康记录类型分别保存草稿，切换 Tab 不会覆盖其他类型的未完成内容。
- 备注和录入方式也属于对应草稿，最终确认后一次批量提交，避免半提交状态。
- 离开页面、返回或取消时会提醒未保存内容；确认弹窗在提交期间会锁定，避免重复写入。
- 批量接口限制请求体大小、记录数量和字段范围，并在服务端统一校验授权与异常状态。

### 设置与更新通知

- “关于我们”页面显示 v1.2.0，并明确列出本版本聚焦的功能方向。
- “消息通知”页面改为展示本次真实更新：消息与语音、AI 回复、紧急求助、健康草稿四项。

## 数据库与部署提醒

本版本包含 #2、#3、#5 所需的数据库迁移。部署 Next.js 代码前，请确认 Supabase 项目已按仓库迁移目录执行对应 SQL；仅更新网页代码不会自动创建数据库表或 RPC。

Android 是在线 WebView 壳，正式包的 `versionName` 为 `1.2.0`、`versionCode` 为 `3`。如果只是更新 EdgeOne 上的网页，已安装的在线壳会在打开新网页时获得网页功能；如果要在应用商店或系统设置中显示 1.2.0，则还需要重新构建并发布 Android 包。
