# 智护银龄 v2.0.0

本版本同时维护两类正式 Android 包，版本号统一为 `2.0.0` / `versionCode 5`。

## 两类安装包

- **网页端 APP（Web 壳）**：功能最接近网页，安装后打开已部署站点。
- **安卓原生 APP**：通知、闹钟、麦克风等系统能力更好，页面需要按 `docs/COMPONENT_SYNC.md` 跟随网页更新。

下载与在线预览见 [官网下载页](https://www.elderstech.husteread.com/app-download/)。

## 这次修了什么

- 首页时间固定为上海时区，并按 30 秒刷新，避免部署设备时区或冻结时钟把问候和时间带偏。
- 所有底栏、页头按安全区重排，不再被刘海或导航条裁切。
- 角色切换、退出登录等确认弹窗提升到页面之上，按钮可点。
- 两端启动图标统一为 `app/` 目录下的品牌图标。

网页、`/api/ping`、Web 壳与原生关于页都显示 `2.0.0`。
