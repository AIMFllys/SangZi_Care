# 07 — AI 对话与意图

> Status: planned · 依赖 [00-shared-server](./00-shared-server.md)

## 1. 背景与对照

对照 [`backend/api/v1/ai_chat.py`](../../../backend/api/v1/ai_chat.py)、[`backend/services/doubao_service.py`](../../../backend/services/doubao_service.py)。

## 2. 目标路由表

| Method | Path | Auth | 要点 |
|--------|------|------|------|
| POST | `/api/v1/ai/chat` | Bearer | 多轮；写入 `ai_conversations`；无 Key 时占位回复 |
| POST | `/api/v1/ai/intent` | Bearer | 意图 JSON |
| GET | `/api/v1/ai/summary/{user_id}` | Bearer | 会话摘要；跨用户需绑定校验 |

**WebSocket** `/api/v1/ai/voice-session`：本任务标为**二期**（EdgeOne WS 支持与鉴权需单独验证）；首版可不实现。

## 3. 文件落点

```
app/api/v1/ai/chat/route.ts
app/api/v1/ai/intent/route.ts
app/api/v1/ai/summary/[user_id]/route.ts
lib/server/doubao.ts
```

## 4. 环境变量

`VOLCANO_ARK_API_KEY`、`VOLCANO_ARK_BASE_URL`、`VOLCANO_ARK_MODEL_ENDPOINT`。

## 5. 验收步骤

1. POST chat 返回文本；库中有记录。
2. intent 返回可解析结构。
3. 无 Key 时不 500，有降级文案。
4. EdgeOne：注意 `maxDuration`（edgeone.json 已 60s）。

## 6. 风险与非目标

- **非目标**：不接 `intentHandlers` 到 UI；不改 `/voice` 视觉；不做 WS。
