```

## 六、状态管理 (`stores/`)

全部采用 **Zustand v5**，按业务域拆分独立 Store。

```
stores/
├── userStore.ts            # 👤 用户状态 (认证/角色/isElder 计算属性)
├── healthStore.ts          # 💓 健康数据 (体征记录 + 最新值 + 异常检测)
├── medicineStore.ts        # 💊 用药管理 (计划/时间线/确认服药)
├── messageStore.ts         # 💬 消息状态 (联系人/消息列表/发送)
├── familyStore.ts          # 👨‍👩‍👧 家庭绑定 (绑定列表/健康摘要)
├── radioStore.ts           # 📻 广播状态 (分类/播放列表/播放控制)
├── voiceStore.ts           # 🎤 语音状态 (录音/识别结果)
├── summaryStore.ts         # 📊 数据汇总 (首页摘要数据)
└── __tests__/              #    5 个 Store 单元测试
```

### Store 状态流向

```
userStore (认证)
    ├──→ familyStore (以 userId 查绑定)
    ├──→ healthStore (以 userId 查体征)
    ├──→ medicineStore (以 userId 查用药)
    └──→ messageStore (以 userId 查消息)

familyStore
    └──→ healthStore.fetchLatest() (家属查老人健康)
```

次文字    #8B7355                       次文字    #6B7394
```

### 设计原则

| 原则 | 实现 |
|------|------|
| 低饱和柔焦渐变 | 背景渐变 + rgba 叠加，避免纯黑纯白 |
| 单屏核心操作 ≤ 2 | 每页最多 1-2 个主操作入口 |
| 拟人化圆润 | 全局圆角 12-36px，FAB 按钮 28px |
| 毛玻璃质感 | `backdrop-filter: blur(20px)` + 半透明白底 |
| 适老化大触控 | 最小触控目标 48px，表单字体 ≥ 16px |
| 动画有温度 | 脉冲呼吸灯、柔和缩放、300ms 过渡 |
