# 桑梓智护 - 本地开发环境指南

## 🚀 快速启动

### 方式一：一键启动（推荐）

**Windows 批处理脚本：**
```bash
# 双击运行或在命令行执行
scripts\dev.bat
```

**PowerShell 脚本：**
```powershell
# 在 PowerShell 中执行
.\scripts\dev.ps1
```

### 方式二：手动启动

#### 1. 启动后端服务

```bash
# 进入后端目录
cd backend

# 激活虚拟环境
venv\Scripts\activate.bat  # Windows CMD
# 或
.\venv\Scripts\Activate.ps1  # PowerShell

# 启动后端服务
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

#### 2. 启动前端服务

在新的终端窗口中：

```bash
# 在项目根目录
npm run dev
```

## 📋 环境要求

- **Node.js**: 18+ (当前: v20.19.6)
- **Python**: 3.9+ (当前: Python 3.14.0)
- **操作系统**: Windows (支持 CMD 和 PowerShell)


## ⚙️ 配置说明

### 环境变量 (.env)

项目根目录的 `.env` 文件包含以下配置：

```env
# 火山引擎 API 配置
VOLCANO_ARK_API_KEY=your-api-key
VOLCANO_APP_ID=your-app-id
VOLCANO_ACCESS_TOKEN=your-access-token
VOLCANO_SECRET_KEY=your-secret-key

# 资源 ID
VOLCANO_TTS_RESOURCE_ID=your-tts-resource-id
VOLCANO_ASR_STREAM_RESOURCE_ID=your-asr-resource-id

# Supabase 配置
SUPABASE_URL=your-supabase-url
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key

# JWT 配置
JWT_SECRET=your-jwt-secret-change-in-production
JWT_ALGORITHM=HS256
JWT_EXPIRE_MINUTES=1440
```

### 前端配置 (package.json)

```json
{
  "scripts": {
```

### 后端配置 (backend/main.py)

- **CORS**: 开发环境允许所有来源
- **端口**: 8000
- **热重载**: 启用 (--reload)

## 🐛 常见问题

### 1. 端口被占用

**问题**: 启动时提示端口 3000 或 8000 已被占用

**解决方案**:
```bash
# 停止现有服务
scripts\stop-dev.bat

# 或手动查找并终止进程
netstat -ano | findstr :3000
taskkill /F /PID <进程ID>
```

### 2. 依赖安装失败

**前端依赖问题**:
```bash
# 清除缓存重新安装
rm -rf node_modules package-lock.json
npm install
```

**后端依赖问题**:
```bash
cd backend
rm -rf venv
python -m venv venv
venv\Scripts\activate.bat
pip install -r requirements.txt
```

### 3. Python 虚拟环境激活失败

**PowerShell 执行策略问题**:
```powershell
# 以管理员身份运行 PowerShell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 4. 后端服务启动失败

**检查 Python 版本**:
```bash
python --version  # 应该是 3.9+
```

**检查依赖是否完整**:
```bash
cd backend
venv\Scripts\activate.bat
pip list
```

### 5. 前端无法连接后端

**检查后端是否运行**:
- 访问 http://localhost:8000/health
- 应该返回 `{"status": "ok"}`

**检查 CORS 配置**:
- 确保 `backend/main.py` 中 CORS 配置正确

## 📝 开发工作流

### 1. 开始开发

```bash
# 1. 拉取最新代码
git pull

# 2. 启动开发环境
scripts\dev.bat

# 3. 开始编码
```

### 2. 提交代码

```bash
# 1. 运行测试
npm test
cd backend && python -m pytest

# 2. 代码检查
npm run lint

# 3. 提交代码
git add .
git commit -m "feat: 添加新功能"
git push
```

### 3. 调试技巧

**前端调试**:
- 使用浏览器开发者工具 (F12)
- React DevTools 扩展
- 查看 Next.js 控制台输出

**后端调试**:
- 查看 uvicorn 控制台输出
- 访问 http://localhost:8000/docs 测试 API
- 使用 Python 调试器 (pdb)
