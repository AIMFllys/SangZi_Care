┌─────────────────────────────────────────────────────────────────────────┐
│                          开发工作流                                     │
└─────────────────────────────────────────────────────────────────────────┘

1. 启动开发环境
   └─ scripts\dev.bat

2. 开发代码
   ├─ 前端: app/, components/, stores/, hooks/
   └─ 后端: backend/api/, backend/services/

3. 自动热重载
   ├─ 前端: Next.js 自动刷新
   └─ 后端: Uvicorn 自动重启

4. 测试功能
   ├─ 浏览器: localhost:3000
   └─ API 文档: localhost:8000/docs

5. 运行测试
   ├─ 前端: npm test
   └─ 后端: python -m pytest

6. 提交代码
   └─ git commit & push

7. 停止服务
   └─ scripts\stop-dev.bat
